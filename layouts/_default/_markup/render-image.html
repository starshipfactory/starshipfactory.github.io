{{- /* Image render hook — routes Markdown images through Hugo's image pipeline. NOT a theme fork: dot-org-hugo-theme ships no render hooks at all, so this adds behaviour rather than freezing a copy of a theme template. It lets plain Markdown `![alt](foo.jpg "title")` get pipeline treatment, so content stays portable Markdown instead of being locked into the theme's {{< img >}} shortcode (which emits a raw and never touches .Resources). Behaviour: - Page-bundle raster images (foo.jpg beside index.md) are converted to WebP, capped at the theme's --content-width, given a 2x srcset where the original is large enough, and emitted with intrinsic width/height so nothing shifts on load. - SVG and GIF bundle resources pass through untouched — Resize cannot handle vectors and would flatten an animated GIF to a single frame. - Root-relative paths are looked up in assets/ (so /img/blog/foo.jpg resolves to assets/img/blog/foo.jpg) and processed the same way. This is how the blog archive gets pipeline treatment while both languages keep sharing one copy of each file — page bundles would force a duplicate of all 58 images into content/en/. - Everything else (remote URLs, paths with no matching asset) falls back to a plain with the destination untouched, so static/ files keep working. Path note: `layouts/_default/_markup/` is the legacy location. Hugo 0.146 moved render hooks to `layouts/_markup/`, but the legacy path still works with no deprecation warning and is compatible with the min: "0.121.0" floor in config/_default/hugo.yaml. Move this file if that floor is ever raised past 0.146. */ -}} {{- $maxWidth := 895 -}}{{/* --content-width, themes/dot-org-hugo-theme/assets/scss/_variables.scss */ -}} {{- $processable := slice "jpeg" "png" "webp" "tiff" "bmp" -}} {{- /* Page-bundle resource first, then a global asset for root-relative paths. The markdown keeps saying /img/blog/foo.jpg even though the file now lives in assets/, which avoids rewriting the image line in all 192 archive files and keeps the German and English copies byte-identical there. */ -}} {{- $res := .Page.Resources.GetMatch .Destination -}} {{- if and (not $res) (hasPrefix .Destination "/") -}} {{- $res = resources.Get (strings.TrimPrefix "/" .Destination) -}} {{- end -}} {{- $alt := .Text -}} {{- $title := .Title -}} {{- if and $res (in $processable $res.MediaType.SubType) -}} {{- $w := cond (gt $res.Width $maxWidth) $maxWidth $res.Width -}} {{- $img := $res.Resize (printf "%dx webp" $w) -}} {{- $srcset := "" -}} {{- $w2x := mul $w 2 -}} {{- if le $w2x $res.Width -}} {{- $retina := $res.Resize (printf "%dx webp" $w2x) -}} {{- $srcset = printf "%s 1x, %s 2x" $img.RelPermalink $retina.RelPermalink -}} {{- end -}} {{- else if $res -}} {{- else -}} {{- end -}}
