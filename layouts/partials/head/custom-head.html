{{- /* Fills the theme's empty head/custom-head.html extension point. NOT a fork — the theme ships this file blank precisely so a site can add to without touching head.html. Adds three things the theme does not emit at all: 1. rel=canonical, so the page declares its own address. 2. rel=alternate hreflang, pairing each page with its other-language version. Without it a search engine has to guess that /holzwerkstatt/ and /en/wood-workshop/ are the same page, and may show the wrong language to a visitor. hreflang values come from each language's languageCode in config/_default/languages.yaml (de-CH, en). 3. Feed autodiscovery, so a browser or reader can find /index.xml from the page itself. 4. noindex on the generated taxonomy pages — see below. */ -}} {{- /* Taxonomy and term pages (/tags/, /tags/laser/, /categories/elektronik/) are generated by Hugo from post front matter, not written by anyone, and there are 282 of them against 15 real content pages per language. 73% of the tag pages list a single post; they all inherit the site-level meta description, so 141 German and 131 English pages shipped byte-identical descriptions; and their titles compete with the pages that should rank — "Laser | Starship Factory" was the title of six different pages. This is the same call already made for Pagefind, which excludes them for the same reason (see the Search section of CLAUDE.md). "follow", not "nofollow": the pages stay useful navigation and crawlers should keep reaching the posts through them. Only the listing itself is kept out of the index. layouts/sitemap.xml drops whatever is noindex, so these leave the sitemap automatically. */ -}} {{- if in (slice "taxonomy" "term") .Kind }} {{- end }} {{- /* Canonical on regular pages and the home page. Paginated lists are deliberately left out: /blog/ and /blog/page/2/ render from one Page object whose .Permalink is always /blog/, so emitting it there would declare every pager page a duplicate of the first and risk deindexing posts only linked from later pages. Hugo exposes no per-pager permalink here, so /blog/ and the taxonomy lists get none — which is what they had before this file existed. The home page is safe to include because layouts/index.html does not paginate. */ -}} {{- if or .IsPage .IsHome }} {{- end }} {{- if .IsTranslated }} {{- range .AllTranslations }} {{- end }} {{- /* German is defaultContentLanguage (config/_default/hugo.yaml) and lives at the site root, so it is what an unmatched locale should be sent to. */ -}} {{- range .AllTranslations }} {{- if eq .Language.Lang "de" }} {{- end }} {{- end }} {{- end }} {{- /* Feed autodiscovery. The type attribute is built with printf/safeHTMLAttr rather than written inline because Go's html/template escapes the "+" in application/rss+xml to + in attribute position.
