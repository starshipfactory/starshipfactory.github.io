Along with our cutting plotter we also received software to drive it. In that connection we
noticed that activating the licence for this software is sometimes accompanied by considerable
friction, and that some people have difficulties with it.

Since we recently managed to activate the software, we want to set out here how best to go
about it:

- When Helocut starts you are asked for the serial number. Simply enter it.
- You are then offered two options for activating the software: online or offline.
  Unfortunately online activation does not work, so choose offline activation here.
- Helocut now generates a licence request file. Save it.
- Open the [Helocut activation page](http://www.helocut.com/Activate.aspx) in your browser and
  upload the file.
- The Helocut page replies with a .HCLIC file to download. If the file is 0 bytes, it has to be
  downloaded again.
- The .HCLIC file has to be renamed to .H5LIC. It is important that the file really is called
  .h5lic afterwards and not .h5lic.hclic.
- The renamed file has to be moved into the Helocut directory (e.g. C:\Programme\HELO\Helocut 5).
- From then on Helocut should start without trouble.

We hope this little guide helps many people activate their plotter software, and that plenty of
new work comes of it!
